| `src/service`          | Byte-dumb storage, security, lifecycle, serving | `store/database.ts`: `openDatabase`, `asStoreError`, `FacetStoreError`, `StoreErrorCode`, `hardenDatabaseFiles`; `store/schema.ts`: `INITIAL_SCHEMA` (canonical DDL — one CREATE TABLE block per table); `lexical/`: `countFencedBlocks`, `countMermaidBlocks`, `computeLexicalExpectations` (CommonMark closer semantics: closer = same char + length ≥ opener + no info string); `security/auth.ts`: `requireBearer`, `requireAnyBearer`, `parseBearer`, `constantTimeEqual`, `checkMutationSecurityHeaders`; `security/host-origin.ts`: `checkHost`, `checkHostOrigin`, `resolveHost`, `isCrossSiteRejection`, `isMissingHostRejection` (DNS-rebinding defense + cross-site forgery guard); `security/http-guards.ts`: `isMutationMethod` (single source of truth shared with `auth.ts`); `security/leases.ts`: `createLeaseManager`, `GalleryLeaseManager` (per-lease unrefed timer, no global poll); `security/token-store.ts`: `createInstallTokenStore` (auto-created mode 0600), `createPromoteTokenStore` (read-only, absence is a typed state), `generateInstallToken`; `lifecycle/process-lock.ts`: `acquireLock`, `releaseLock`, `readLockMetadata`, `writeLockMetadata`, `isLockStale`, `isPidAlive` (atomic O_EXCL with metadata `{pid,startTime,port,contractVersion}`); `lifecycle/idle-controller.ts`: `createIdleController` (single state machine — reasons: request / lease / validation, count→0 schedules idle timer, no DB/fs/polling); `lifecycle/orphan-cleanup.ts`: `runOrphanCleanup` (stale lock whose pid is dead + stray WAL/SHM sidecars); `router.ts`: `buildRouter`, `handleCommand` (orchestration: Host → mutation-headers → auth → envelope → dispatch); `router-guards.ts`: `readRequestMeta`, `readCappedBody`, `parseBody`, `INVALID_JSON`, `statusFor`, `RAW_BODY_CAP_BYTES` (per-guard helpers used by `router.ts`); `http-utils.ts`: `envelopeResponse`, `generateRequestId`, `pickRequestId` (shared between router and stream); `dispatcher.ts`: `dispatch` (pure command switch); `stream.ts`: `handleStream` (SSE route, authed fetch + ReadableStream, lease-gated via `X-Gallery-Lease` header — never a URL query param); `server.ts`: `startFacetService`, `RunningService` (loopback 127.0.0.1 port 0; orphan cleanup → store → tokens → lease/idle → bind → lock; idle-driven stop); `main.ts`: argv/env entrypoint, structured ready line on STDERR, SIGTERM/SIGINT graceful stop |
