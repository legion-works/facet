# Structure

| Directory              | Purpose                                 | Public symbols                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/contracts` | Wire-format schemas and protocol types  | `envelope.ts`: `FACET_SCHEMA_VERSION`, `FacetEnvelopeSchema`, `parseEnvelope`, `okEnvelope`, `errEnvelope`; `commands.ts`: `CommandRequestSchema`, `CommandResultSchema`, `IMPLEMENTED_COMMANDS`, `RESERVED_COMMANDS`, `checkCommandImplemented`, `checkArtifactTypeSupported`, `normalizeReadBackTier`; `events.ts`: `RevisionCommittedEventSchema`, `StreamEventSchema`; `validation.ts`: `ValidationTierSchema`, `RenderStatusSchema`, `VerdictSchema`, `Tier0InputSchema`, `Tier0ResultSchema`, `Tier1InputSchema`, `Tier1ResultSchema`; `artifact.ts`: `ArtifactTypeSchema`, `Artifact`, `Revision`, `RenderRun`, `Template` |
| `src/shared/errors`    | Cross-boundary typed errors             | `facet-error.ts`: `FacetError`, `FacetErrorCodes`, `FacetErrorCode`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `src/shared/config`    | Tunable limits and runtime path layout  | `limits.ts`: `SOURCE_CAP_BYTES`, `MAX_MERMAID_BLOCKS`, `MAX_MERMAID_NODES`, `MAX_NESTING_DEPTH`, `MAX_SVG_BYTES`, `MAX_SVG_ROOTS`, `DEFAULT_LIST_LIMIT`, `MAX_LIST_LIMIT`; `paths.ts`: `computeFacetPaths`, `FacetRuntimePaths`                                                                                                                                                                                                                                                                                                                                                                                                   |
| `src/service`          | Byte-dumb storage and serving service   | `store/`: `openDatabase`, `runMigrations`, `ArtifactRepository`; `lexical/`: `countFencedBlocks`, `countMermaidBlocks`, `computeLexicalExpectations`                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `src/cli`              | User-facing command line interface      | Planned                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `src/gallery-web`      | Sandboxed gallery shell and frames      | Planned (`frame/` is the future zod-free bundle, enforced by the boundary guard)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `src/validation`       | Tiered validation workers               | Planned                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `src/harness-adapters` | Harness integration adapters            | Planned                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `scripts`              | Build and repository checks             | `verify-decisions.ts`, `egress-penetration.ts`, `check-boundaries.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `tests`                | Unit, integration, and acceptance tests | `unit/contracts.test.ts`, `unit/lexical.test.ts`, `unit/store.test.ts`, `integration/crash-safety.test.ts`; `acceptance/` (red by design), `helpers/facet-testkit.ts`, `fixtures/`                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `docs`                 | Product and decision documentation      | `docs/decisions`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
