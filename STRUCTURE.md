# Structure

Gallery source reads use the lease-gated `GET /api/v1/gallery/source` route alongside bootstrap, release, and revision SSE; responses include source bytes and the latest stored verdict or `null`.

Public extension points: `RendererRegistry`, `Tier0ValidatorRegistry`, `Tier1ProbeRegistry`, `EvidenceStore`, `CliTransport`, `ArtifactBuilder`, `ExportSink`, `AuthorizationPolicy`, `SearchIndex`, and `FormBridge`. Artifact code never gains host capabilities.

Recent opaque-content additions: `src/service/store/schema.ts` exports
`V3_SCHEMA_FRAGMENT` and `V4_SCHEMA_FRAGMENT`, and migrations apply v3 and v4
after the existing v2 fragment. `src/shared/config/limits.ts` and
`src/validation/tier1/limits.ts` expose the pinned browser and screenshot

## Export slot

- Shared contracts: `ExportRequestSchema`, `ExportResultSchema`, and
  `ExportSidecarSchema`.
- Errors: `evidence_unavailable` covers missing or unavailable stored render
  evidence.
- Service: `service/export.ts` builds source and stored-render results;
  `service/stored-verdict.ts` resolves the selected stored verdict.
- Repository: `getRevisionBySha`, `getLatestRevision`, and `listRenderRuns`
  provide revision and evidence lookups; the dispatcher owns the export arm.
- CLI: `cli/commands/export.ts` resolves paths and owns filesystem writes,
  including the mandatory sidecar.
